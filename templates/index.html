⌨️ 단축키 안내: • A / D or ← / → : 이전 / 다음 사진
• S or Ctrl+S : 라벨 저장
• Q (or Del) : 선택 폴리곤 삭제
• E : 새 폴리곤 그리기 (연속 2회: 클래스 선택창)
• 0~9 : 그리기 클래스 숫자 단축키 즉시 변경
• Enter : 그리기 완료 (첫 점 연결)
• Space + 드래그 : 화면 이동(Pan)
• 마우스 휠 : 마우스 위치 중심 확대/축소
• 꼭짓점 우클릭 : 해당 꼭짓점 삭제
• Esc : 그리기 취소 및 선택 모드 복귀
